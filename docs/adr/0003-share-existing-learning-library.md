# Dùng chung Learning Library hiện có với extension

Desktop sẽ có giao diện và chức năng tương đương Translation Extension, liên kết cùng Learning Account và lưu nội dung vào Learning Library hiện có. Người dùng chọn giữ quản lý thư viện và ôn tập trên website thay vì đưa cả website học tập vào desktop; quyết định này giữ một thư viện chung giữa các thiết bị và giới hạn desktop ở vai trò dịch, hỗ trợ học và lưu nội dung. Cách liên kết tài khoản và các hành vi tương tác trên Windows sẽ được chốt riêng trong đặc tả.
