# Desktop hoạt động độc lập với extension trình duyệt

Desktop phải dùng được chỉ với bộ cài desktop, kể cả khi dịch nội dung trong Chrome/Edge. Người dùng chọn tích hợp qua Windows thay vì yêu cầu một extension làm cầu nối lấy vùng chọn và thay chữ trong trang web; lựa chọn này loại bỏ phụ thuộc cài đặt trình duyệt nhưng đòi hỏi kiểm chứng mức tương thích với từng ứng dụng. Giao diện và chức năng của extension vẫn là tham chiếu sản phẩm, còn các hành vi phụ thuộc trình duyệt phải được đặc tả lại cho desktop độc lập.
